## 1.0.0（2026-11-23）

首个正式版本。基于 uni-app x 蒸汽模式，覆盖 Android、iOS、鸿蒙、H5 与微信小程序，依赖 `easemob-websdk 5.2.0`。

### 会话与消息

- 会话列表支持搜索、全部/未读/@我/单聊/群组筛选、置顶、免打扰、未读、草稿、自动同步、骨架屏、空态与失败重试。
- 聊天页支持文本、图片、语音、视频、文件、自定义与复合消息接收展示；提供历史加载、引用定位、撤回、重新编辑、失败重发、删除、复制、编辑、置顶消息和时间分隔。
- 支持单聊已读回执、可选群聊已读人数、typing、@ 提及、消息发送状态自定义、附件上传进度、发送失败原因与服务端审核修改标识。
- 图片、视频与文件支持长按下载。App/小程序可保存图片和视频到相册，并尝试打开下载的文档；H5 使用浏览器下载。
- 视频消息提供五端全屏播放器。App 端先下载完整视频再播放，并显示下载进度。

### 群组与通讯录

- 支持群列表、建群、群公告、群名编辑、成员邀请/移除、管理员设置、群主转让、全员禁言、退群/解散和群系统通知。
- 通讯录提供入口页、好友列表、字母索引、搜索、好友备注、删除好友、好友申请与群邀请处理。
- 聊天信息页支持单聊与群聊资料、置顶/免打扰、清空记录、删除会话及单聊删除好友。

### 接入与业务扩展

- `EmKit` 统一提供初始化、登录、Token 续期、消息与会话操作、群组/联系人管理、未读数、日志和原生 SDK 客户端入口。
- 支持 `sendText` 业务扩展字段、`sendCustom`、自定义消息整卡插槽、顶部业务条、输入栏业务入口、快捷回复、自定义消息菜单和本地系统提示。
- 输入栏支持整栏自绘、emoji 面板与图片气泡注入点，以及单行/多行模式、页面级功能集和菜单覆盖。
- AI 流式消息支持分片合并、乱序/丢片补偿、合批刷新、底部跟随、异常状态和富格式插槽。
- 提供可运行的 `templates/chat-only`，包含登录恢复、单聊天页、微信小程序双分包及构建检查。

### 主题、组件与样式

- 内置明暗主题、跟随系统、中英文与扩展语言；主题和语言偏好可持久化，并同步原生导航栏与 tabBar。
- 提供 38 个页面级与原子组件，包括通用开关、水印、空态、骨架屏、弹层、选人、加载状态和消息气泡。
- 支持全局品牌色与头像形状、`--em-*` 设计变量、`custom-class` / `custom-style` 和具名插槽定制。
- 所有页面组件支持标题与宿主样式透出；会话、聊天、通讯录、好友和群组页面支持组件级水印。

### 连接、可靠性与隐私

- 连接状态条区分连接中、重连中、离线、Token 过期、设备超限和被踢下线；支持自动 Token 续期与手动 `renewToken`。
- 网络离线时直接提示并保留失败消息；发送超时、服务端删除、多端删除和内容审核事件同步到本地状态。
- 会话、联系人、群资料和用户资料请求具备账号代次与旧响应隔离；大批量用户资料按 100 人分片，免打扰状态按 20 条增量校正。
- 非当前会话保留最近 100 条内存消息，重新进入时拉取最新页；登出清理账号数据、草稿、临时附件和待处理请求。
- 原始同步载荷默认不写入日志；调试日志需显式开启，导出前由宿主脱敏。

### 平台与工程

- 仅支持 uni-app x 蒸汽模式，不支持经典 uni-app、Vue2、nvue 或 vdom 模式。
- 微信小程序支持 `sub-im` 页面分包与 `sub-sdk` SDK 分包，提供开发监听、构建后处理、配置自愈和主包体积检查。
- 文档门户提供快速开始、页面/组件/API/配置参考、平台差异、界面截图、业务接入和排错指南，并提供 8 份宿主接入 Agent Skills。
- 示例工程包含五端运行配置、媒体权限、鸿蒙权限与签名指引，以及 Android/iOS 发行所需的 WebSocket 模块声明。

### 当前边界

- H5 使用移动端布局，不提供桌面宽屏、多栏或 H5 录音入口。
- App 不内置系统文件选择器；发送文件需宿主注册附件 provider，未注册时隐藏文件入口。
- App 视频需等待完整下载；实际解码能力取决于系统。微信小程序下载需配置合法域名，文档打开类型以微信支持范围为准。
- 文件单击不触发下载，下载入口位于长按菜单；语音消息不提供下载入口。
- 消息列表使用 `scroll-view` 全量渲染；完整本地历史持久化由宿主按业务需要实现。
- 当前不包含消息转发、黑名单、群共享文件、公开群入群审批、群名片、群已读成员明细、消息搜索和 presence 在线状态。
